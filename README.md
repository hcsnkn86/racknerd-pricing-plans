## 机房选错，配置再高也白搭

中国用户从国内访问，机房位置的影响比多 1 GB 内存大得多。按访问体感排：洛杉矶 DC-02 标了亚洲优化线路，电信联通走它延迟最低，晚高峰大致 195ms；洛杉矶 DC-03 是三网优化，有时会开出原生 IP 段，对 IP 归属敏感的服务更适合；西雅图对移动用户更友好，晚高峰比洛杉矶稳一些，延迟约 200ms；圣何塞属于美西常规水平，看时段。

美东的达拉斯、纽约、芝加哥、阿什本，物理距离决定延迟 250ms 起步。阿姆斯特丹、伦敦、都柏林、斯特拉斯堡这些欧洲节点 280ms 以上，只有跑欧洲业务才值得选。

能不能选到 DC-02，要看套餐和当时的库存。常驻特价和节日特价的可选机房不一样，节日那批常常锁掉几个位置。下单时下拉框里没有的位置就是没有，别指望买完再换。RackNerd 每个机房有 Looking Glass，地址形如 `lg-lax02.racknerd.com`，下单前可以从机房回 ping 你自己的网络，比看别人的测评数字靠谱。

## 几个没人提前说的限制

**流量超了只限速，不停机。** 月流量用完之后机器会被限速到 10Mbps，不关机、不额外扣费，下个计费周期自动恢复。部分特价套餐的购物车里带 free bandwidth doubling 选项，下单时留意一下能白拿双倍流量。这条对流量估算没把握的人很有用，至少不会半夜被停服。

**72 小时内可以免费换一次 IP。** 开出来的 IP 如果被墙，在后台自助换掉就行。超过 72 小时再换，有资料说收 $3，也有说按工单报价几美元一次，具体金额问客服。想彻底换机房则是另一回事：要么按客服报价付迁移费，要么重新下单，数据自己备份搬。

**只能升级，不能降级。** 同系列往上补差价升级，重启一次、停机一分钟左右生效。想降配置只能销毁重开，数据不保留。

**支付宝要看结账页。** 有资料说全面支持支付宝、PayPal、信用卡和加密货币，也有说部分套餐和活动才支持、节日特价多数走 PayPal 或信用卡。结账页支付方式下拉框里有没有 Alipay，就是最终答案。

**IPv6 可以免费申请。** 洛杉矶和法国机房下单后开工单，最多要 100 个，其他机房在陆续支持。

**最便宜的几档最常缺货。** 价格压得最低的套餐也是最容易卖断的，看到有货、机房也对，就别拖。
